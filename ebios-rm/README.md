# EBIOS Risk Manager — Velmora Payments (fictional)

A complete risk analysis using **EBIOS Risk Manager**, the risk-assessment method published by ANSSI (the French national cybersecurity agency). It continues the [maturity assessment](../README.md) of the same fictional fintech, and every treatment measure links back to a maturity finding (G-01, I-02, B-01…) and to an ISO 27001:2022 Annex A control.

**Velmora Payments is a fictional company.** The workshops are written in French, the method's working language.

## Key results

- 3 critical feared events (platform outage, data leak, payment fraud).
- 4 retained risk sources: ransomware gang, fraudsters, data resellers, malicious insider.
- 2 ecosystem stakeholders in the danger zone (external developers, merchants), brought back under control.
- 2 unacceptable risks (ransomware, data theft) reduced to tolerable/acceptable in 6 months, mainly through 5 low-cost measures (MFA, immutable tested backups, no standing admin accounts, secret scanning, access reviews).

*Indicative analysis for portfolio purposes.*
